# School-Deck Project
Hardware:
Dsiplay: WeAct Studio 1.54 Inch Epaper Module 200 x 200 pixels
Microcontroller: ESP32-C6

Planned Functions of project:
MVP:
display school schedule and automatically update it with time progressing
OGP:
be able to create any school schedule on display with simple system
be able to look into a subject and see further information like teacher, room and potentially date of future exams
automatically connect to internet to the school page and gather data from the online substitution plan, filter out the needed data and automatically display any changes to the school schedule on the display
